# Contexte actuel

Alina Mobile est le client Flutter de participation à une room. Le rôle réseau est `CLIENT`. Les écrans sont l'authentification, l'accueil et la room client. L'inscription demande un code reçu par email avant l'activation du compte. La room expose les messages et les sondages.

Le dossier `../alina/frontend` est une référence en lecture seule pour les contrats API, les topics LiveKit et le design. Tout travail de ce projet doit rester dans `alina-mobile`.
